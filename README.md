## The joke

> The office printer has been 'out of order' since 2023, which technically makes it our longest-serving employee — it never calls in sick, and it never prints either.

## How it works

`main.py` (Python 3.13, standard library only) writes that single line to `/output/entry.txt`. No network, no dependencies, deterministic — run it twice and the output is byte-identical.

```sh
python3 main.py
cat /output/entry.txt
```
